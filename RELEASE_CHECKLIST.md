# Release Checklist

Use this checklist before creating a stable curriculum release.

## Content

- [ ] Table of contents is current.
- [ ] Lecture and chapter links work.
- [ ] Notebook links work.
- [ ] Video links work.
- [ ] Important technical claims have primary or authoritative sources.
- [ ] Time-sensitive claims have a checked date.
- [ ] Deprecated tooling is marked clearly.

## Reproducibility

- [ ] Key notebooks have been executed.
- [ ] Colab paths work where supported.
- [ ] Hardware requirements are documented.
- [ ] Dependencies are documented.
- [ ] Results and known limitations are recorded.
- [ ] Experiments identify the code version and data/model versions.

## Research metadata

- [ ] CITATION.cff is valid.
- [ ] CITATION.md is current.
- [ ] Release notes explain substantial changes.
- [ ] Any DOI metadata is updated after archival.

## Quality

- [ ] No credentials or private data are present.
- [ ] Third-party assets have appropriate attribution.
- [ ] Broken links have been checked.
- [ ] Teaching explanations match current terminology.
