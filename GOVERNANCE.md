# Governance

## Purpose

The repository exists to develop and share rigorous knowledge for training, evaluating, deploying, and managing language models.

## Maintainer responsibilities

Maintainers are responsible for technical quality, educational coherence, citation and provenance, reproducibility standards, constructive contribution review, release discipline, and security/privacy hygiene.

## Decision principles

When multiple approaches are plausible, prefer the approach that is evidence-supported, reproducible, teaches transferable reasoning, minimizes unnecessary complexity, and makes assumptions explicit.

## Technical disagreement

Resolve disagreements with evidence, experiments, references, and clearly stated assumptions. When evidence cannot settle a question, document the uncertainty instead of hiding it.

## Curriculum changes

Significant curriculum changes should identify what changed, why, the evidence motivating the change, affected material, and any learning implications.

## Contributions and credit

The project is open to external contributions through GitHub issues and pull requests. Significant contributors should be credited in release notes and, where appropriate, citation metadata.
