# Support

For educational questions:

1. Search the textbook and notebook material.
2. Search existing GitHub issues.
3. Open a new issue when a reproducible problem is not already documented.

When opening an issue, include:

- the relevant chapter/notebook;
- what you expected;
- what happened;
- environment information;
- the smallest reproduction you can provide.

For questions about a paper or method, include the citation or link being discussed.
