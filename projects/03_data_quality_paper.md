# Project 3 — Data Quality Research Study

## Goal

Test whether a data intervention changes model quality.

Possible interventions:
- filtering;
- deduplication;
- language balancing;
- domain mixture;
- synthetic-data filtering.

## Required design

Hold architecture and training budget constant as far as practical.

Produce:
- hypothesis;
- baseline;
- intervention;
- ablation;
- evaluation;
- figure/table;
- failure analysis;
- reproduction instructions.

## Publication path

Turn the final result into a 4–8 page research report with a clear limitations section.
