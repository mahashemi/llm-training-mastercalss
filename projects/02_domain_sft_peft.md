# Project 2 — Domain Adaptation With SFT and PEFT

## Goal

Take a small open-weight causal model and adapt it to a clearly defined domain/behavior.

## Required comparison

- prompt-only baseline;
- SFT;
- LoRA;
- optional QLoRA;
- retained-capability evaluation.

## Deliverables

Dataset card, experiment card, evaluation report, adapter/model artifact, resource comparison, and failure analysis.
